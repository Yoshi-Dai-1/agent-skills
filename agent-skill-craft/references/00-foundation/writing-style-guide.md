# AI Agent Writing Style & Vocabulary Guidelines

## 1. 文体プロトコル
- すべての指示文章の文末は「〜すること」「〜を実行すること」で統一すること。
- 人間向けの解説文や第三者客観表現、時間軸依存の文言（メタ表現や過去・未来を仮定した表現）を完全に排除すること。

## 2. 決定論的条件分岐（Condition-Action & If-Else Completeness）
- 曖昧な副詞（不確定な状態を示す副詞全般）を排除すること。
- 条件（If）を記述する場合は、未定義状態によるハルシネーションを防止するため、必ず対となる否定条件（Else / Fallback）を「〇〇の場合はAを実行し、〇〇が存在しない場合はBを実行すること」のように明示すること。
- 人間の意図や開発都合ではなく、今このターンのコンテキスト内の状態（「ファイルが存在する/存在しない」等）に基づいて分岐させること。

## 3. 順次読み込みにおける実行ターンの分離原則 (Turn Separation Protocol)
- 順序付き連番ファイル（`01-`, `02-` 等）をロードして段階的にコード・成果物を適用する場合、一括読み込みによる適用漏れ・失念を防止するため、「1ファイルを読み込んでコードを出力・確定させた後、次のファイルを読み込む」という実行ターンの分離プロトコルを記述すること。
- 意図的に複数ファイルを同時に並列参照・比較分析させる場合は、その旨（「同時にコンテキストにロードして比較すること」等）を明示すること。

## 4. 用語の一元化（同義語混用の禁止）
- 同一のオブジェクト、概念、状態に対して複数の異なる単語を使用しないこと。
- スキル定義時に主要単語を確定し、全ファイルで統一適用すること。
