# Self-Audit & Quality Verification Checklist

作成・改修したスキルファイル群に対し、以下の全件チェックを実行すること。

1. **記述視点・時間詞チェック**: 人間向けの第三者客観表現や時間軸依存の文言が混入していないこと。
2. **If-Else網羅性チェック**: 条件節（If）に対し、対となる否定条件（Else / Fallback）が明記されていること。
3. **実行ターン分離チェック**: 順序適用ファイルに対し、一括読み込みを防止するターン分離指示または並列読み込みの明示がなされていること。
4. **語彙の一貫性チェック**: 単一概念に対して表記ゆれやシノニム混用が発生していないこと。
5. **相対パス参照チェック**: `SKILL.md` 内に記述された全ファイルの参照パスが存在すること。
6. **曖昧表現チェック**: 判断に迷う不確定な副詞が含まれていないこと。
