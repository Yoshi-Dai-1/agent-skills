# 監査規律（Audit Protocol）

対象スキルの自己監査・レビューを実施するときの規律。**不備を検出すること自体ではなく、検出の主張のしかたと同反復の制御に関する規則**である。

## 1. 主張には証拠を添える

- 不備を主張する場合、**対象ファイルの現行の原文引用と行番号（`path:line`）を必ず添える**。引用を欠く指摘は採用しない。
- 引用は監査時点で読み込んだ現行ファイルから取得する。**記憶や以前の読み込み結果の文面を根拠にしない。** 直前の読み込み内容が当該行と一致するか、報告前に照合する。
- 機械走査（スクリプト・grep）で確認した内容は、そのコマンドと出力を添える。
- 判断（可読性・適切さ・一貫性など、主観が介在する判断）は、判断の根拠となる対象箇所を引用したうえで述べる。

## 2. 未決済台帳（Ledger）で反復を制御する

- 監査を開始する時、まず未決済事項の一覧（台帳）を作成する。各事項に通し番号を付け、ファイル、箇所、種別、状態、根拠を記述する。
- **以降の監査報告は台帳の差分のみを出力する。** 決済済み（修正済み・誤り・該当なしと確定済み）の事項を再掲しない。
- 清算した事項は台帳上で状態を「closed」にし、理由を記録する。台帳は `scripts/audit-ledger.py` で管理する。
- 台帳ファイルは**対象スキルとは別の作業領域**に置く。既定の置き場所は対象スキルと同階層の `ledger.json` である。対象スキルのディレクトリ内に作ると、そのファイル自体が未参照ファイルとして扱われる。
- **台帳が管理する対象は、監査で検出した不備と、出力評価で残った未解決事項の 2 つである。** 両者を同じ台帳に置き、区別の種別で管理する。
- 台帳が空（未決済ゼロ）になった時点で監査を終了する。**終了条件を満たした後の再監査を禁止する。** 無限ループは監査の妨げになる。
- ただし、**修正を実施した後の再走査は禁止の対象外とする。** 再走査の対象は、その修正で決済した項目と、それによって新たに発生しうる影響範囲に限る。この再走査を新たな監査とは区別し、台帳に新たな未決済事項が生じないことを確認して終了する。

## 3. 検出なしの明言

- 走査の結果、不備が検出されなかった場合は、**「検出なし」と明示的に報告する。** 報告を省略しない。
- **「何かを見つけなければ」という圧力で見つからない問題を作らない。** 些細な表記差を不備として捻出しない。
- 使い分けとして正当な語差（意味の異なる対象を指す別語）は不備として扱わない。その場合は「対象相違による正当な使い分け」と明示する。

## 4. 多視点監査の運用条件

- 複数の観点（フローの分岐網羅性、スクリプトの精度、言語・表記など）を**互いに独立した担当者に委譲して並列に監査させる**手法は、実効性が確認されている。再監査（同じ観点を別担当で再確認する）で誤検出と未検出の両方を潰す。
- ただし費用が高いため、**大きな改修の確定前など重要な局面に限定**して使う。日常の逐次修正ではコストが割に合わない。
- サブエージェントの監査で得られた指摘は、**依然として §1 の証拠規律で照合する**。サブエージェントの報告も引用なしの場合は採用しない。

## 5. 機械走査と目視の分離

- 機械で判定できるもの（存在・構文・リンク・名前規則・文字種・用語ゆれ・サイズ予算）は機械で検出する。
- 主観が介在するもの（日本語の自然さ、設計の妥当性、指示の妥当性）は機械では判定できないため、人が読んでレビューする。
- 機械走査と目視の守備範囲を混同しない。**機械で素通りした項目を「合格」と表示しない。** 検証手段の守備範囲外の項目は「対象外」と明示する。

## 6. 修正の順序

1. 検出した不備を台帳に登録する（証拠付き）。
2. **同一の根本原因に紐づく不備をまとめて修正する。** 個別文面の表面修正を先行させない。表面修正は次の監査で再発する。
3. 修正後、該当箇所を再走査して、修正が実際に当該箇所に及んだことを確認する。
4. 台帳を清算し、監査報告する。監査報告の構成は「検出した不備（決済済みを含む）」「未決済の残存」「対象外（検証手段の守備範囲外）の項目」の 3 区分とする。
   対象スキルの**実行時の完了報告**は別の様式であり、`references/execution-protocol.md` §4 の 4 区分（変更点・解消・確認・残存ギャップ）を使う。2 つの様式を混ぜない。
5. 報告において、**実施していないことを実施したように記述しない。** 対象の範囲（何件中何件）、省略した手段と理由、検証できなかった項目を明記する。
