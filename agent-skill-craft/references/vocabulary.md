# 語彙表（Vocabulary）

本スキルと、対象スキルの作成および監査で使う語を 1 つに定める。**同一の対象には同一の語を使う。** 異なる対象を指す語は、意味を区別して明示する。

## 1. 意味論的役割語

| 語 | 定義 | この語を使う文脈 |
|---|---|---|
| **AI エージェント** | スキルの指示を実行する主体 | 指示文の主語。実行時の判断者 |
| **利用者** | スキルを使い、指示を出す人 | 利用者への確認・承認・提示・結果提示 |
| **読み手** | 生成された成果物を読む人 | 成果物の文体の決定。利用者とは限らない（自動処理・後続処理も含む） |
| **対象スキル** | 作成・監査・改修の対象となる Agent Skill | 参照先・所有者のスキル |
| **作者** | 対象スキルの指示を書く主体（AI エージェントまたは人） | 執筆・改修の文脈 |

**判別の要点**: 「利用者」は指示を出し「読み手」は成果物を読む。同一人物が両方を兼ねる場合があるため、語は分けるが人物を分けるわけではない。

## 2. 統一語と禁止する表記揺れ

機械可読な正本は `assets/vocabulary.json` の `forbidden_variants` である。下の表と同じ内容を保つ。

| 統一語 | 禁止する表記 | 禁止の理由 |
|---|---|---|
| 利用者 | ユーザー | 同一対象を指す 2 語。同じものを指す語を増やさない |
| 読み込む | 読込む | 表記ゆれ。送り仮名の基準に照らして「読み込む」に統一 |
| 使う | 用いる／使用する | 表記ゆれ。「使う」に統一 |
| 発動 | 発火／活性化／活性度 | 同一対象を指す語。「発動」に統一 |
| 検証 | 検査 | 「検証」に統一。基準との比較により適合かを判定する行為 |
| 記述 | 記載 | 「記述」に統一。文書へ文言を残す行為を指す |
| スキル | 技能 | 「スキル」に統一 |
| AI エージェント | AIエージェント | 表記ゆれ。空白の有無で統一する |

## 3. 意味が異なるため并存させる語

以下は対象が異なるため同一の語にしない。ただし各定義を本表に置き、参照する文書では定義を省略しない。

| 語 | 意味 | 違いの要点 |
|---|---|---|
| 検証 | 基準に対して適合か否かを判定する | 判定の根拠が基準との比較。機械的に行える |
| 確認 | 状態が想定どおりかを確かめる | 判定の根拠が観察。人の目でも機械でもよい |
| 実行 | 手続きを動作させる | を主体とする語 |
| 適用 | 規則を効かせる・対象とする | を客体とする語。「適用範囲」はこの意味 |
| 修正 | 判明した不備を是正する | 変更の量が小さい |
| 改修 | 構造や設計を変更する | 変更の量が大きい |
| 完了条件 | 1 件の作業が終わることを判定する基準 | 作業の側の基準 |
| 終了条件 | 反復を止める基準 | ループの側の基準 |
| 適用範囲 | 対象スキルの手法が及ぶ領域 | スキルの側の線引き |
| 範囲外 | 適用範囲に含まれない | 対象スキルの線引き |
| 対象外 | 検証・監査の守備範囲外 | 検証手段の線引き |
| 規律 | 本スキルの規則 | メタスキルの側の語 |
| 規約 | 対象スキルの既存規程 | 対象側の語 |

## 4. 表記の基準

- **仮名遣い**: 現代の仮名遣いとする。歴史的仮名遣いは用いない。
- **送り仮名**: 送り仮名の付け方に従う。判断に迷った場合は、参照元の表記に照らして最も一般的な表記を採る。
- **公用文**: スキルの指示文は公用文の体裁とする。主語を省略し、「〜すること」で終止する。
- **数値と単位**: 数値と単位の間の空白は全ファイルで統一する（例: 「1 行」「2 件」）。
- **助詞「等」の前**: 空白を置かない（例: 「ファイルの有無、モード、件数等」）。
- **括弧**: 日本語の文中の括弧は全角とする。コード・数式・固有名詞は半角とする。
- **句読点**: 日本語の文中は全角の読点「、」と句点「。」とする。
- **助数詞**: 漢数字とアラビア数字を混在させない。件数と回数はアラビア数字とする（例: 「3 回」「1 行目」）。

## 5. 機械チェック

語彙揺れは `assets/vocabulary.json` に機械可読な形で保持し、`python3 scripts/validate-skill.py <対象スキルディレクトリ> --vocabulary assets/vocabulary.json` で検査する。対象スキルも同様の語彙表を `assets/vocabulary.json` に置けば同じ検査が有効になる。
