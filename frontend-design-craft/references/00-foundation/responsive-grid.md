# Responsive Layout Grid Guidelines

## 0. 適用範囲
- 本ファイルは画面幅対応の原則のみを定める。具体的数値（ブレイクポイント幅・列数・マージン・ガター等）は本ファイルに定めない。数値を独自に補完・引用しないこと。

## 1. 適応レイアウトの原則
- ビューポート相対で設計すること。固定 px 幅の指定を禁止し、流体レイアウト（liquid layout）と相対単位（%, em/rem）で構成すること。
- 狭い画面では単一ペイン、広い画面では複数ペインへ段階的に移行すること。ペイン分割時は各ペインの幅を均等割合で定め、恣意的な固定幅を避けること。
- 画面遷移型（狭）と並列表示型（広）を使い分けること。一覧＋詳細、主領域＋補助パネル、カードのグリッド配置は、幅に応じて列数・表示方式を変えること。
- 回転・折りたたみ・分割画面・マルチウィンドウ・自由変形による幅変化に追随し、レイアウトが破綻しないこと。

## 2. リフローと拡大の保証
- テキストは支援技術なしに 200% まで拡大でき、内容・機能を失わないこと（WCAG 1.4.4）。拡大時にテキスト・画像・操作部が切断・重なり・消失しないこと。
- 320 CSS px 幅でも縦スクロールのみで全内容に到達できること。二次元スクロールを要求しないこと（WCAG 1.4.10）。例外として意味保持に二次元配置が必須の場合のみ許容する。
- テキスト間隔の上書き（行高 1.5倍・段落間隔 2倍・字間 0.12倍・語間 0.16倍）で内容・機能を失わないこと（WCAG 1.4.12）。
