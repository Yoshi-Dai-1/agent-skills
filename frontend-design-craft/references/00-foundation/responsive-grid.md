# Responsive Grid & Breakpoint Protocol

## 1. レスポンシブブレイクポイント
画面サイズに応じて以下のカラム構造を適用すること。

- **Compact (< 600dp)**: 4カラム、マージン 16dp、ガター 16dp
- **Medium (600dp - 839dp)**: 8カラム、マージン 32dp、ガター 24dp
- **Expanded (>= 840dp)**: 12カラム、マージン 200dp (max)、ガター 24dp

## 2. タップターゲットサイズ
- モバイルおよびタッチ操作環境において、インタラクティブ要素の最小タップ領域を 48x48dp 以上確保すること。
