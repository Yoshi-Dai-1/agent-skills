# Material 3 Expressive Static Tokens (Sequence 01)

## 1. カラーロール (Color Roles)
HEX直接指定を禁止し、以下の役割ベーストークンで割り当てること。

- `Primary` / `On Primary`: 主要アクション・重要ボタン
- `Primary Container` / `On Primary Container`: ハイライト領域
- `Surface` / `On Surface`: 背景および基本テキスト
- `Outline` / `Outline Variant`: 境界線・区切り線

## 2. タイポグラフィ (Typography Scale)
- Display, Headline, Title, Body, Label の5スケール規約に従うこと。

## 3. 形状スケール (Shape Scale)
- Extra Small (4px) 〜 Extra Large (28px), Full (9999px) の角丸スケールを適用すること。
