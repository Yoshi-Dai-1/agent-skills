# Material 3 Layout System Specifications

## 0. 適用範囲
- 本ファイルは M3 の画面幅数値の正本とする。適応の原則（単→複ペイン、リフロー保証）は `00-foundation/responsive-grid.md` に従うこと。

## 1. ブレイクポイントと画面幅（M3正本値）
画面幅（Width）に応じた5つの標準ブレイクポイント（旧称 window size classes）を定義する。

- **Compact (< 600dp / px)**:
  - カラム数: 4
  - マージン: 16dp
  - ガター (Gutter): 16dp
  - 対象: スマートフォン縦画面
  - ペイン: 1（推奨）

- **Medium (600dp〜839dp)**:
  - カラム数: 8
  - マージン: 24dp
  - ガター: 24dp
  - 対象: タブレット縦画面、折りたたみデバイス
  - ペイン: 1（推奨）または2

- **Expanded (840dp〜1199dp)**:
  - カラム数: 12
  - マージン: 24dp（前後マージン）
  - ガター: 24dp（ペイン間スペーサー 24dp）
  - 対象: スマートフォン横画面、タブレット横画面、デスクトップ
  - ペイン: 1または2（推奨）

- **Large (1200dp〜1599dp)**:
  - カラム数: 12
  - マージン: 24dp〜32dp（可変）
  - ガター: 24dp
  - 対象: デスクトップ
  - ペイン: 1または2（推奨）

- **Extra-large (>= 1600dp)**:
  - カラム数: 12
  - マージン: 24dp〜32dp（可変）
  - ガター: 24dp
  - 対象: デスクトップ、ウルトラワイド
  - ペイン: 1〜3（推奨）

## 2. カノニカル・レイアウトパターン (Canonical Layouts)
- **List-Detail**: 左側にリスト領域、右側に詳細領域を配置。Compact画面では画面遷移、広い画面では2カラム分割。
- **Feed**: カード型コンポーネントをグリッド状に並べる。画面幅に応じて1〜4列にスケール。
- **Supporting Pane**: メイン領域の隣に一時的または常駐型の補助パネルを配置。
