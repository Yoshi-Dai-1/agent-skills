# Material 3 Component Placement & Usage Specs

## 1. 主要コンポーネント選定ルール
- **Top App Bar**: 画面上部のコンテキストタイトルの表示およびプライマリアクション。
- **Navigation Rail / Drawer**: タブレット・デスクトップ画面（Medium / Expanded）でのプライマリ画面切替。
- **Floating Action Button (FAB)**: 画面内で最も重要かつ単一のプライマリアクション（新規作成、送信等）。
- **Cards**: 関連する情報・アクションを視覚的にカプセル化する領域。
